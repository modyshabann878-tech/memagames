# تفعيل التحليلات (لكل المستخدمين) — مجاني

التطبيق بيسجّل أحداث مجهولة الهوية: فتح اللعبة، اللعبة اللي اتفتحت، التحدي اللي اتبدأ، عدد اللاعبين، عدد الأسئلة المجاب عليها، والساعة.
مفيش أسماء ولا بيانات شخصية؛ بس رقم عشوائي لكل جهاز لحساب عدد المستخدمين المختلفين.

## الخطوات
1. افتح https://sheets.google.com وأنشئ Sheet جديد (اسمه أي حاجة).
2. من القائمة: Extensions → Apps Script. امسح الكود اللي فيه والصق محتوى `analytics_server.gs`.
3. غيّر `READ_KEY` لكلمة سر خاصة بيك (متشاركهاش مع حد).
4. Deploy → New deployment → Type: Web app → Execute as: Me → Who has access: Anyone → Deploy. انسخ رابط الـ Web app.
5. افتح `config.js` وحط الرابط في `ANALYTICS_URL`، وارفع الملفات تاني على الاستضافة.
6. افتح موقعك مرة واحدة من جهازك بالرابط `https://موقعك/?dev=1` (ده بيفعّل الباب السري على جهازك بس).
7. دوس 5 مرات متتالية على اسم "Mema Games" → اكتب الرقم السري (الافتراضي 7391، غيّره من اللوحة) → 📊 التحليلات → اكتب READ_KEY → تحديث.

## ملاحظات
- جهازك (وضع المطوّر) مستبعد من الإحصائيات الحقيقية، إلا لو فعّلت "احسب نشاط جهازي كمان".
- لإلغاء وضع المطوّر على جهازك: افتح `?dev=0`.
- الباب السري والتحليلات حماية من جهة المتصفح بس؛ ما بتمنعش مستخدم تقني مصمم. بيانات التحليلات نفسها محمية بالـ READ_KEY على السيرفر.
